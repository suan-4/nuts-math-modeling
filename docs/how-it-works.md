# Nuts-MathModeling的运行原理

## 一句话理解

Nuts-MathModeling把一次真实数模项目中的工作方法、写作规范和常见错误，整理成AI能按任务读取的规则与检查工具，帮助它在建模、求解、作图、论文和提交文件之间保持一致。

它使用当前AI本身的能力来工作：没有训练一个新模型，没有内置万能算法库，也没有把参赛论文做成向量数据库。装上skill不会自动获得Word、绘图、联网或计算环境；这些能力由使用它的AI工具与本地环境提供。

## 从一次请求开始

1. 用户给出赛题、数据、论文或模板，并说明要新建、精修还是检查。AI工具通过技能名称与描述选择本skill，或由用户显式调用`$nuts-math-modeling`。
2. 读取`SKILL.md`，了解任务范围、输入条件、优先顺序和工作流程。它约束工作方式，例如不凭空补参数、不重置用户锁定的图尺寸。
3. 按需读取`references`里的文档。修公式就读公式规范，画图就读图表流程；全文任务再同时检查结果、模板与交付。不要求每次把19份参考全部读一遍。
4. AI结合实际材料完成分析，并调用当前环境中的文件、代码、绘图与文档工具。规则说明如何做，具体建模与修改由AI执行；需要团队判断的假设仍需明确说明。
5. 对照源数据和正式结果核验，再检查生成的图表、Word/PDF与最终压缩包。发现冲突时沿模型、代码、结果和文章追查来源，修复后检查受影响的部分。

这里的“按需读取”是文档路由，不是一个隐藏的多智能体系统；是否使用子任务代理由具体环境与用户授权决定。

## 三种文件各有什么用

| 部分 | 实际作用 | 举例 |
|---|---|---|
| `SKILL.md` | 工作规则与任务路由入口 | 先回答题目，再安排结果解释与检验 |
| `references/*.md` | 按场景调用的方法和案例 | 大括号内左对齐、流程箭头预留空间、图前后话术 |
| `scripts/*.py` | 可重复执行的有限静态检查 | ZIP缺文件、源码语法、个人路径、模拟汇总污染 |

`agents/openai.yaml`提供支持它的工具所用的显示名称与默认请求，不是数值求解器。运行脚本需要当前环境有Python，生成Word或图像需要另有相应工具和库。

## 用一条公式举例

用户提出“问题四的公式没对齐”。AI先看这些公式是否属于同一组条件，再参考规范决定如何组织：同一数学对象使用一个自动伸缩的左大括号，各行内部左对齐，一个组共用一个编号；若下标被裁切，则检查公式段落行距、内部行距和表格行高。

具体修改Word与导出PDF依赖当前环境能否读取、修改和渲染文件。本包没有一个现成脚本能对任意Word文档一键修好公式。它提供操作规则和验收要求，AI据此实施，最后仍需检查真实渲染。

## 用一次作图举例

用户提出“画全域含水率达标图”。AI先确定图要回答的判定问题，找到正式数值结果及阈值，选择能体现阈值穿越的画法，再决定采样星号、终点标注、图例位置与插入尺寸。

绘图代码由AI按当前数据编写或修改；本包没有附送一套适用于所有题目的绘图程序。复用的是“先确定证据、再设计画面、核对数据、按纸面尺寸验收”的做法。

## 三个检查脚本的边界

- `audit_text.py`：检查文本中的占位符、摘要结果线索、可能的单位矛盾和图表引用。基于文本规则，会有误报和漏报，不能判断公式正确性或真实版面。
- `audit_final_surface.py`：提示泛化标题、最优性或稳健性等高风险表述。它发现值得复核的文字，不能判定整篇论文是否严谨。
- `audit_support_package.py`：读取ZIP检查成员、必需文件、CRC、非法名称、个人绝对路径及可选Python语法编译，识别一种典型的模拟汇总污染模式。它不执行里面的程序，不验证Excel数值，也不证明求解正确。

14项自动测试验证的是这些工具对已编写测试案例的行为，不是对未来任意题目的建模能力、Word格式或科学结论的认证。

## 和一句长提示词有什么区别

它同样通过说明文字影响AI工作，但将通用规则、细分参考、真实反例和可执行脚本分开保存，可以按需读取、版本管理、复用和测试。优势是减少遗漏并让步骤可检查，效果仍取决于底层AI、输入质量、工具环境及人工核验。

## 可以怎样对外介绍

> 我把这次广东省一等奖数模项目中，从读题、建模和求解，到公式、图表、论文排版和提交检查的做法，整理成了Nuts-MathModeling。它让AI按任务读取相应的规范，并配合实际数据和工具完成工作，重点减少公式排版、图表解释、结果同步和打包提交中的反复返工。

避免介绍为“一键生成省一论文”“训练过获奖论文的专属大模型”“自动保证公式与模型正确”或“14项测试证明AI不会出错”；当前实现不支持这些说法。

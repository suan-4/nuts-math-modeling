# 做题人的中文表述与可用句式

## 写得具体，比替换“AI词”更重要

每段保留真实动作、对象、因果和结果。不要把“而不是”“大致”一律当禁词；问题在于是否空泛、是否遮掩证据。删除没有新增信息的句子，不通过同义词替换或强行并成长句制造所谓人工风格。承接用户认可的措辞和术语。

| 场景 | 可直接改写的句式 | 要填的事实 |
|---|---|---|
| 问题分析开头 | 本次建模的整体流程如图1所示，下面分别分析各问题的求解思路。 | 图确实说明整体依赖 |
| 每问章首 | 本问需要求得……。在……条件下，下面建立……模型并计算……。 | 题目的核心输出 |
| 承接前问 | 本问沿用问题二的……，新增……，据此计算……。 | 延用的是方程、参数还是状态 |
| 推导前 | 对……微元作……平衡，积累量等于……，因此有： | 守恒关系及符号 |
| 推导后 | 将……代入并令……趋于零，得到……方程： | 实际数学变换 |
| 求解困难 | ……使方程具有非线性，因此在每个时间步内迭代更新……。 | 困难与算法如何对应 |
| 结果引出 | 采用……离散……方程，并用……求解；提取……时刻和位置的结果，列于表X。 | 具体方法、采样规则 |
| 文件交付 | 完整结果按……间隔保留……位小数，保存于resultN.xlsx，程序见附录BN。 | 原题文件名及格式 |
| 图前 | 根据……计算结果，绘制……随……变化的曲线，如图X所示。 | 数据、横纵轴、目的 |
| 图后 | 由图X可以看出，……由……变为……，说明……。 | 一个决定性变化及依据 |
| 表前 | 从……中提取题目指定的……，所得……列于表X。 | 本表独有信息 |
| 表后 | 由上表可以看出，……；其中……，因此……。 | 对题目有用的数值/差异 |
| 检验 | 将……由……改为……后，……最大变化为……，该结论适用于……。 | 比较范围与误差单位 |

这些是结构参考，不是每段都必须套的固定模版。图后不必再加一整句“因此为下一步奠定基础”。有具体用途就说明，没有则停在准确解释处。

## 过渡句放在哪里

章首通常交代本问任务、继承/新增条件和下文求解目标。父标题下面有多个不同功能的子节且关系不明显时，放一条桥接句；子节已经自然承接时不要再加。

“下面……”的宾语写题目要解决的事，例如“下面计算前3h药材温度和干基含水率的径向分布”；不要写成“下面对6.1—6.2模型建立和算法设计进行论述”。不能把题目要求求解温湿场，改说成题目要求给出物性关系；物性关系可能只是已知输入。

例：

- **建模部分：** 为计算预热阶段内部温湿分布，先确定计算区域及初边值条件，再由能量守恒和水分守恒建立径向传递方程。
- **数值部分：** 中心处的圆柱几何项不宜直接求值，扩散系数又随状态变化，因此采用环形控制体离散，并在时间步内迭代更新物性。
- **前问重算：** 问题二在全程采用新的物性关系，因此从题给初始状态重新计算。前问末态用于比较，不作为新初值。
- **全域判定：** 为确认所有位置均达到要求，逐时求取全截面含水率最大值，再在穿越阈值的相邻时刻间插值。

## 结果段的顺序

题目要填表时，先交代模型如何计算、提取哪些时空位置、文件如何保存，再给出指定表格、解释主要差异，随后用辅助图与检验支撑。结果不能埋在一页页算法介绍后没有明确回答。

图表解释必须是普通正文，不用孤立加粗的“结论：”“分析：”卡片。普通结果段不要复述每个单元格；选极值、终点、差值、转折及关键位置。表和图相邻时避免分别写两遍完全相同的数字。

## 名称与单位要按对象区分

材料状态可统一为“干基含水率”，空气的水分浓度/湿度口径另行定义；两者同为kg/kg也不能全文机械替换。指定结果表标题若沿用原题“水分浓度”，说明与状态量的对应，不能把原题表格改得无法识别。

本次用户偏好1800s、0.1cm等紧凑写法，不人为插入空格；这是项目偏好，其他模板要求SI空格时以其为准。术语全篇一致，数值的四位小数是显示精度，不能写成已证明四位小数准确。

## 摘要压缩与长句

第一段只保留背景矛盾、总模型和具体解决的计算任务；不要声称完成了没有目标函数、决策变量与优化过程的“工艺优化”“能耗降低”。每问交代任务、关键方法、量化结果，题目要求Excel时写原文件名。用户要求字数不变时用删除重复词给新增结果让位，不硬塞长句。

“按百分位报告”宜写成“保留两位小数为”，避免被理解为统计百分位数。长句可以承载一条清楚的因果关系，但不能靠删除标点把多个不同逻辑层次压在一起。

## 有约束的精修

先说问题造成什么阅读/数学风险，再提出最小有用修改。用户指定摘要不动、只改表1表2、只改公式组、不要改图尺寸时，将其作为锁定项。局部修复后检查上下文一致性，未授权的其他问题另列报告。

压缩页数优先删重复推导、重复验证说明、重复结论和空过渡。不能先缩小字号、砍掉关键边界条件、删除规定结果列或用四舍五入掩盖差异。完成后核对摘要、正文、图表、结论的数字与编号。
